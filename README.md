# usage-view

Claude Code のコンテキスト・5時間枠・週間枠の使用量を、ステータスラインに1行で出す mod です。
重い作業(大きな PR の差分のレビューなど)の途中で、会話の詰まりすぎや使用量の制限に気づけるようにするのが目的です。

## 表示

入力欄の下に、次の1行が出ます(VS Code では行の頭に `usage-view plugin` と付きます)。

```
ctx ■□□□□ 10% │ 5h ■■□□□ 35%(0h12m) │ 7d ■■□□□ 45%(1d8h)
```

| 項目 | 意味 |
|---|---|
| `ctx` | コンテキスト(会話の詰まり具合)の使用率 |
| `5h` | 5時間枠の使用率。括弧はリセットまでの時間 |
| `7d` | 週間枠の使用率。括弧はリセットまでの時間 |

- 四角は5個で、1つが 20%。四捨五入した % から数える(10% で1個、30% で2個、90% で5個)。細かい値は % の数字で見る
- リセットまでの時間は、1日以上なら `1d8h`(日と時間)、1日未満なら `0h12m`(時間と分)。分は切り捨て。過ぎていたら `0h0m`
- 値が無い項目は出さない。3つとも無ければ行ごと消える
  - `ctx`:セッションの始め、最初の応答が来るまでは無い
  - `5h`・`7d`:サブスクリプションで使っていないとき(API キーなど)や、最初の応答が来るまでは無い

## いつ書き直すか

- メインスレッドの各ターンの後
- 5時間枠・週間枠が1ポイント動いたとき
- ターンの合間は 60 秒ごと(リセットまでの時間を進めるため)

## やらないこと

- 色は付けない(VS Code では色の指定が文字のまま出るため)。使用量は % の数字で見る
- パネル・通知・振り返りのレポートは作らない
- このターンでの増分、モデル名、API 料金換算の費用は出さない
- コンテキストには時間を付けない
- `five_hour`・`seven_day` 以外の枠(ゲートウェイの `spend_limit` など)は出さない
- on / off のコマンドは無い(消すときは下の「消し方」)

## 入れ方

このリポジトリをマーケットプレイスとして登録して入れます。

```
claude plugin marketplace add AndoYuto87/usage-view
claude plugin install usage-view@usage-view
```

## 消し方

```
claude plugin disable usage-view@usage-view
```

## テスト

リポジトリの直下で:

```
claude plugin validate ./usage-view
claude plugin test ./usage-view
```
